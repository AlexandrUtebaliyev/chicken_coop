# Решения, принятые без подтверждения

Коротко — что решил сам и почему, раз задача требовала работать автономно (см. CLAUDE.md).

- **Статус марки, если ячейка «Статус» пуста**: отгружено ≥ заказа → «Отгружено»; иначе готово ≥ заказа → «Готово»; иначе готово > 0 → «Готово частично»; иначе покрашено > 0 → «Покраска»; иначе изготовлено > 0 → «Изготовление»; иначе «Не начато». Формула подобрана и проверена по реальным строкам снимка (`Б-6`, `Б-10`, `МП-1`, `ПР1-9` и др.) — во всех случаях совпала с готовым статусом из таблицы.
- **Число вида `"1,968"` (запятая без точки)**: если все группы после первой запятой ровно по 3 цифры — это тысячи (`1968`), иначе запятая — десятичный разделитель (`12,5` → `12.5`). Правило из PROMPT.md было неполным для этого случая, выбрал вариант, который даёт верные эталонные суммы.
- **Наименование группы при равной частоте первых слов** (пример из PROMPT.md: «Колонна / Стойка» для группы СТ): беру все слова с максимальной частотой, сортирую по алфавиту и соединяю через « / ». Если слово одно — показываю его одно, без слэша.
- **Сортировка «Марки»**: «по готовности» — по возрастанию (сначала наименее готовые, это то, что обычно нужно увидеть в первую очередь в цехе); «по весу» — по убыванию (сначала самые тяжёлые). В PROMPT.md направление не указано.
- **Экран птичника по умолчанию**: переключатель «Только недостающие / Все» открывается в режиме «Только недостающие» — это чаще нужная информация на складе.
- **Статус птичника «Собирается»**: отдельного цвета в палитре PROMPT.md для него нет, использовал синий (`--status-partial`), как у статуса марки «Готово частично» — тот же смысл «в процессе».
- **Иконка приложения**: логотипа компании не было, сделал простой домик (ассоциация с «птичником») в фирменном синем цвете интерфейса; сгенерирован PNG вручную через Node (`zlib` + ручная упаковка PNG-чанков), без внешних библиотек и сети.
- **Journal (История) недоступна офлайн без кэша**: не считаю это фатальной ошибкой всего приложения — карточка марки открывается, просто блок истории показывает «История недоступна», т.к. основная функция (готовность) не зависит от журнала.
- **Pull-to-refresh**: порог срабатывания — свайп вниз на 90px от верха списка, без отдельного визуального индикатора (используется тот же крутящийся значок «Обновить» в шапке, что и при нажатии кнопки).
