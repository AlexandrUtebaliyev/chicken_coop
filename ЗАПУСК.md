# Как запустить Claude Code на эту задачу

1. Открыть PowerShell в папке проекта и запустить в авто-режиме:

   ```powershell
   cd C:\Users\utebaliyev.a\Documents\Projects\chicken_coop
   claude --permission-mode auto
   ```

   В строке состояния должно быть `auto mode on`. Если нет — нажимать `Shift+Tab`, пока не появится.
   (Не использовать `--dangerously-skip-permissions` на рабочем ПК — он отключает все проверки.)

2. Отправить одно сообщение:

   ```
   Сделай приложение по PROMPT.md, следуя правилам CLAUDE.md. Работай автономно до конца без вопросов.
   ```

   Чтобы он гарантированно не остановился раньше времени, можно вместо этого задать цель:

   ```
   /goal node tests\check.mjs проходит, приложение работает на живой таблице, README.md и DECISIONS.md написаны
   ```

3. Когда закончит — прочитать его отчёт и `DECISIONS.md` (какие решения он принял сам).
   Публикацию на GitHub Pages (`git push`) он сделает только после вашего «да».

Файлы:
- `PROMPT.md` — что сделать (под таблицу «Готовность_марок_ВОМ_журнал»);
- `CLAUDE.md` — как работать (автономно, проверка, Windows);
- `tests\fixtures\` — снимок таблицы на 18.10.2026 для проверки расчётов;
- `prompt_gotovnost_marok.md` — старый общий промт, больше не нужен.
